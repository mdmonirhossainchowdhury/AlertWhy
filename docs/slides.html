Open Agent Hackathon 2026 · Track 02 · The Agent That Can Explain Why

AlertWhy

AML alerts, explained — with cited evidence, a confidence score, and a cost meter.

Problem & users

Banks run transaction monitoring. Most alerts are false positives. Analysts spend ~25 minutes per case (assumption) across core banking, KYC, sanctions, news, and reference data. Regulators require an auditable why.

Users: AML analysts and MLROs. Global: any bank or fintech with TM alerts.

Solution

  • Investigate one alert across five fragmented sources, in place.
  • Return ESCALATE / CLOSE / REVIEW with risk, confidence, evidence chain, and next steps.
  • Never auto-accuse: mixed signals → REVIEW; strong sanctions → always escalate.

Agent workflow

Planner ↔ Executor ↔ Evaluator, with H-MEM recall and a citation-guarded narrator.

The evidence engine decides the verdict. The LLM only explains. Invented citations are rejected.

Architecture

Five sources → Zetaris query-in-place → AlertWhy agent → verdict + audit trail → Meterless Nightshift AI + H-MEM memory.

Same SQL on live Zetaris as on the local DuckDB fallback. The UI refuses to call the fallback “Zetaris”.

Tech stack

Python, FastAPI, DuckDB (offline demo), vanilla JS UI, pytest. Built in Cursor. Optional NVIDIA Nemotron as a secondary OpenAI-compatible narrator.

Zetaris

Every number comes from Federation.query(). Three JDBC datasources (core_pg, kyc_pg, screen_pg) stay in place. Sensitive bank data is not copied into the agent.

Meterless

Nightshift is the primary AI runtime (plan, critic, guarded SQL, narration). H-MEM stores analyst decisions so later alerts about the same customer recall prior cases. Usage per investigation is metered as an estimate, not as billing.

What is unique

  • Mitigating evidence (same-name sanctions with different DOB, payroll batches, stable history) can close false positives.
  • Citation guard: the model cannot invent evidence IDs.
  • Honest uncertainty and a human confirm/override path written into H-MEM.

Results (honest)

19/19 on planted synthetic scenarios — pipeline validation, not real-world accuracy. Tests cover the Zetaris REST contract (fakes), Nightshift provider (fakes), SQL guard, H-MEM, agent loop, and API.

NVIDIA

Optional Nemotron narration via MODEL_BASE_URL / NEMOTRON_MODEL when Nightshift is not the narrator. Do not claim it in the video unless it is configured.
